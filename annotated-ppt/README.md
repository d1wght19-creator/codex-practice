## 标注说明

- 人工✓：原文明确存在人工动作，并不表示整道工序全部由人工完成。
- 人工?：根据典型流程推定为人工，现场作业方式需确认。
- 人机?：典型人机配合，分别写明人工动作及设备边界，需现场确认。
- 设备：核心工艺由设备执行，辅助人工边界需确认。

原文未写明的人机分工属于推定，不能作为现场已确认事实。各工厂自动化程度不同，正式分工以现场 SOP、设备文件及工艺人员确认为准。
