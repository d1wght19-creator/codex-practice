# 13类产品制造流程｜中文配音PPT讲解视频

每份原PPT对应一个独立MP4。视频保留29页画面，按每页的讲解时长自动翻页。

- 中文合成配音，开头已注明使用合成语音；没有冒充现场讲师或实拍记录。
- 视频格式：H.264，1280×720；音频格式：AAC。普通浏览器、Windows播放器或VLC等支持标准MP4的播放器可打开。
- 每份附可选中文字幕和29个页面章节；播放器是否显示章节取决于软件。字幕未强制覆盖PPT正文，需要时在播放器字幕菜单启用。
- 保留原资料对人工、设备以及待核事项的区分。典型流程和推定分工仍需按现场SOP、BOM和设备文件确认。

## 内容组织

第1—16页为原流程介绍与现场核实信息，第17页说明人工作业标注，第18—29页补充人工与设备分工。讲解按页概述重点，页面保留完整工序文字；需要细读时可暂停。

视频是用户PPT的配音讲解版，没有增加机器人动作动画或工厂实拍内容。旁白按PPT原文整理；通用推定和具体工艺参数不视为已验证现场事实。
